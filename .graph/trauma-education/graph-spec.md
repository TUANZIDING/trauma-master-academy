# TraumaMaster Academy 治理型 Graph 合同

**合同状态：teaching_release_approved_limited_scope（教学发布已批准；适用范围受限）**
**图版本：1**
**最后更新：2026-07-19**

本合同定义“谁可提出、谁独立核验、谁可否决、何时停止”的控制架构。项目发起人已批准面向学生的受限教学发布；它不把课程转化为床旁诊疗指令、本院正式操作规程或个体化治疗方案，也不以总体批准替代专题定位和病例授权记录。

## 根目标与边界

在不提供床旁决策支持、不泄露病例信息、不弱化指南边界的前提下，使医学生能在标准化模拟中形成可报告的创伤问题表征、识别不确定性，并完成复评与交接。

根目标由**课程负责人（姓名隐匿，创伤方向主任医师）**与**指定创伤临床审核人（姓名隐匿，创伤方向主任医师）**共同拥有。正式记录保留职务、日期与批准范围，姓名按隐私要求不公开。

不属于本合同或课程的范围：诊断、处方、操作步骤、剂量/阈值、床旁指令、医疗器械功能，以及未授权或未完成脱敏审核的真实病例公开使用。

## 为什么必须使用 Graph

页面排版、图标、非医学文案和静态检查是直接流程；图片生成、模板完整性、双语结构配对和渲染检查可使用有界单循环。

但医学内容发布、真实病例与影像使用、来源更新、双语语义和公开版本维护互相制约：同一内容作者不能自行确认指南准确性、脱敏完成或可公开发布。故这些工作必须形成治理型 Graph，而不是依靠“生成后自检”。

## 节点、独立性与证据

机器可读的节点、边和证据字段见 [graph.json](graph.json)。最低责任分离如下：

| 责任 | 可做什么 | 不可自行决定 |
|---|---|---|
| 内容编写 | 形成候选模块、主张-来源映射、双语稿 | 自证医学准确、脱敏完成或准予发布 |
| 临床/来源核验 | 审查主张的版本、范围和保守表述 | 代替课程负责人决定教学取舍 |
| 隐私与影像核验 | 审查授权、脱敏、展示范围及影像风险 | 用技术检查替代授权或专科判断 |
| 双语复核 | 核对不确定性、限制语与安全边界 | 弱化任一语言中的医学限制 |
| 技术验证 | 产出可复现结构与资源检查报告 | 判断医学正确性或发布资格 |
| 发布风险复核 | 独立确认反指标未被代理指标掩盖 | 以完成率或视觉效果替代真实学习与安全 |
| 仲裁与人工闸门 | 处理冲突、批准或拒绝 | 在证据或审批缺失时“默认通过” |

## 冻结的现实锚点

以下项目不能由内容生成、评分、技术验证或发布循环改写：

1. 已批准的 [临床安全边界](../../docs/CLINICAL_SAFETY_BOUNDARY.md)；
2. 每项主张的官方/授权来源、组织、版本、范围、定位和时效记录；来源索引不是批准；
3. 真实病例、Word 文档、影像与派生资产的受限来源、授权、脱敏和展示范围；
4. 候选发布的代码版本、可复现验证报告、人工审查和签署决定；
5. 审批权、否决权、停止条件和回滚门槛。

任何变更均须留下旧版、变更理由、风险评估、批准人和生效范围。

## 审批闸门

| 闸门 | 必要批准 | 不能由什么替代 |
|---|---|---|
| 学生可见医学模块 | 指定创伤临床审核人 + 课程负责人 | AI、来源列表、自动化测试 |
| 真实病例或影像 | 隐私/病例授权审核人；影像还需相关专科审核人 | 文件重命名、裁剪或视觉去标识的自行判断 |
| 本院流程表述 | 本院流程授权负责人 | 外部指南或一般性经验 |
| 实质双语医学改动 | 双语医学编辑/临床审核人 | 字符串配对检查 |
| 恢复已回滚版本 | 原审批链重新确认受影响范围 | 旧的发布记录 |

审批人姓名按隐私要求隐匿，职务均记录为创伤方向主任医师；批准日期与范围写入审批记录。任何后续范围变更仍须新增正式记录。

## 仲裁优先级

患者安全、隐私、授权和证据边界，高于本地适用性与双语语义一致性；后者高于教学体验；教学体验高于视觉丰富度、页面数量、交付速度和答题完成率。医学、隐私/授权和本地流程审核人对其所属风险可否决。冲突应由课程负责人记录书面决定；无书面解除的否决保持有效。

## 停止、回滚与升级

立即停止候选发布并移交相应责任人，如果出现：来源缺失或范围不符、脱敏/授权不明、原始与合成材料混淆、实质双语偏差、生成图暗示诊疗指令、未确认的本院流程表述、技术验证失败，或核验结论无法仲裁。

已发布版本如发现医学错误、隐私/版权风险、来源失效、误导性教学效果或安全边界被突破，技术维护人应冻结受影响版本并保留证据包；课程负责人启动仲裁，医学/隐私/授权问题分别移交指定审核人。只有修正、重新核验和完整审批链完成后，才能恢复发布。
