# Trauma Master Academy project map / 项目地图

This file defines the public identity and scope of the complete project. `Trauma Skills Academy` is one component of `Trauma Master Academy`, not the repository's overall name.

本文件定义整体项目的公开身份与范围。`Trauma Skills Academy` 是 `Trauma Master Academy` 的一个组成部分，不是仓库总名称。

## 1. Whole learning pathway / 完整学习链

```text
Prehospital information / 院前信息
        ↓
Trauma team activation / 创伤团队启动
        ↓
Arrival handover and shared board / 到院交接与共享信息板
        ↓
xABCDE primary survey / xABCDE 初级评估
        ↓
Injury-specific mini modules / 病种迷你模块
        ↓
Bedside tests, imaging, and trends / 床旁检查、影像与趋势
        ↓
Supervised procedural simulation / 监督下操作模拟
        ↓
Resources, transfer, and definitive capability / 资源、转运与确定性能力
        ↓
Reassessment and debrief / 再评估与复盘
```

## 2. Five core courses / 五门主干课程

1. Trauma-bay orientation / 第一次进入创伤抢救室
2. xABCDE primary-survey reasoning / xABCDE 初评推理
3. Pelvic trauma and occult haemorrhage / 骨盆创伤与隐匿出血
4. Trauma-care chain / 创伤救治链
5. Trauma and disaster medicine / 创伤急救与灾难医学

## 3. Disease mini-module matrix / 病种迷你模块矩阵

- Traumatic brain injury / 颅脑损伤
- Chest trauma and unstable chest wall / 胸部外伤与胸壁不稳定
- Abdominal organ injury and bleeding / 腹部脏器损伤与出血
- Integrated polytrauma / 多发伤综合推理
- Pelvic trauma / 骨盆创伤
- Additional modules are labelled by their current evidence and review state / 其他模块按证据与审核状态标示

## 4. Progressive teaching cases / 渐进式教学病例

- Cervical-spine and hip-dislocation teaching case / 颈椎与髋关节损伤教学病例
- Abdominal haemorrhagic-shock case / 腹部失血性休克病例
- Polytrauma and unexplained-shock reassessment case / 多发伤与未解释休克再评估病例
- Disaster and multi-casualty synthetic cases / 灾难与多伤员合成病例

Cases separate four layers: case facts, imaging descriptions, teaching inferences, and privacy/authorisation scope.

病例按四层记录：病例事实、影像描述、教学推断、隐私与授权范围。

## 5. Trauma Skills Academy / 创伤技能学院

The procedural-simulation sub-academy currently contains nine skills:

技能模拟子学院目前包含九项技能：

1. Bag-valve-mask ventilation / 球囊面罩通气
2. Tracheal intubation / 气管插管
3. Emergency front-of-neck airway / 紧急颈前气道（环甲膜切开）
4. Emergency chest decompression / 胸腔紧急减压
5. Tube thoracostomy / 胸腔闭式引流
6. EFAST
7. Tourniquet application / 止血带
8. Pelvic binder / 骨盆束带
9. Temporary limb splinting / 四肢临时固定

Each skill uses task-specific images, observation prompts, team organisation, physiological confirmation, failure recognition, and reassessment. Complete invasive technique remains within supervised local credentialing.

每项技能包含针对性图片、观察任务、团队组织、生理验证、失败识别与复评。完整侵入性技术仍受本地资质与教师监督限制。

## 6. Evidence and governance / 证据与治理

## 7. Public-release statement / 公开发布声明

The repository is an educational and simulation resource. It does not replace certified trauma courses, local protocols, clinical supervision, patient-specific judgement, or formal procedural credentialing.

本仓库是教学与模拟资源，不替代正式创伤认证课程、本院流程、临床监督、个体化判断或操作资质认证。
