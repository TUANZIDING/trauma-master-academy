# Trauma Disaster Instructor Mode

## Purpose

Instructor Mode supports live classroom delivery without turning the course into clinical decision support.

## Controls

- Full screen: expands the browser presentation surface.
- Hide/reveal answer: toggles explanatory answer blocks.
- Next information: releases the next scenario panel.
- Pause scenario: freezes challenge timer and shows pause state.
- Trigger deterioration: changes synthetic trend language.
- Show vital signs: shows trend monitor panel.
- Show team roles: shows role cards.
- Start countdown: starts a classroom countdown timer.
- Start debrief: opens debrief prompts.
- Reset scenario: returns the scenario to initial state.
- Export lesson plan: downloads a text lesson plan for classroom use.

## Display Rules

- Instructor-only controls remain visible only in Instructor Mode.
- Challenge mode hides answers until requested.
- Learner mode shows hints and formative feedback.
- All modes keep review labels visible.
