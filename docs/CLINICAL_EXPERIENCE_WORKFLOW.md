# Clinical experience to courseware / 临床经验转化工作流

## Input contract / 输入约定

The clinician may narrate freely. The workflow preserves the narration, then separates objective record, recollection, investigation report, teaching inference, evidence-supported claim, and local workflow.

医生可以自由口述。工作流先保留原始叙述，再区分病历客观记录、回顾性口述、影像或检验报告、教学推断、证据支持结论和本院流程。

## Interview cycle / 采访循环

1. Restate the learning goal and audience.
2. Run a blindspot scan.
3. Ask no more than three high-leverage questions.
4. Build a relative timeline and retain conflicting accounts.
5. Build Known / Unknown / Feared and xABCDE priority maps.
6. Convert only generalizable teaching assertions into claim candidates.
7. Locate current, lawful, authoritative evidence.
8. Compare structure-only, instructor-preview, and student-release routes.
9. Obtain explicit implementation approval.
10. Validate technical, evidence, bilingual, privacy, rights, and local-adaptation gates separately.

## Learner sequence / 学员学习序列

`Initial presentation -> learner response -> submit judgment -> reveal new information -> explain reasoning -> reprioritize -> patient reassessment -> system reassessment -> structured handover`

Answers remain hidden by default. Reference reasoning is an evidence-bounded teaching explanation, not the only possible bedside answer.

答案默认隐藏。参考推理是受证据边界约束的教学解释，不宣称是所有临床情境中的唯一答案。

## Stop conditions / 停止条件

- A material conflict could change the clinical teaching point.
- The source supports a different population or setting.
- No direct evidence location can be recorded.
- The item depends on an unconfirmed local workflow.
- De-identification or teaching authorization is incomplete.
- A protected course passage would need to be copied.

When a stop condition is present, the item remains reviewer-only, is converted to a synthetic structure, or is removed from student content.
